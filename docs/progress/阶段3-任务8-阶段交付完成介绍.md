## 从零运行例子

```powershell
docker compose up -d
pwsh -NoProfile -ExecutionPolicy Bypass -File .\scripts\Invoke-Maven.ps1 test
pwsh -NoProfile -ExecutionPolicy Bypass -File .\scripts\Invoke-Maven.ps1 package '-DskipTests'
java -jar .\target\luckyhub-0.0.1-SNAPSHOT.jar
```

浏览器打开 `http://localhost:8080/swagger-ui.html`。按照 API 手册依次完成管理员建商品和分配 MALL 库存、建券并发券、建会员产品；普通用户购买会员、下单和创建支付；管理员模拟支付成功。最后订单应为 `PAID`、优惠券为 `USED`、库存已消耗一件。

## 现在项目能做什么

当前系统已经可以把实物或虚拟商品放入简化商城，以现金价购买；会员先打折，优惠券再抵扣；也可以用积分走独立积分兑换。抽奖核心仍保持原有流程。阶段 3 的支付是本地模拟，物流和真实外部券/积分/会员系统仍属于后续阶段。
