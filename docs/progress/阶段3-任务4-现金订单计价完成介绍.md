# 阶段 3 · 任务 4：现金订单计价完成介绍

## 完成内容

商品目录新增现金可购 SKU 快照；订单服务完成单 SKU、1～100 件立即购买。创建订单在一个事务中完成价格快照、锁券和 `MALL` 库存预占，并以订单号幂等。

## 计价例子

商品原价 100 元，用户是 9 折会员，并使用满 80 减 20 券：

```text
原价：10000 分
会员折扣：1000 分
会员后金额：9000 分
优惠券：2000 分
应付：7000 分（70 元）
```

顺序不能交换。订单保存以上每一步以及商品名、SKU、图片和单价，后续商品调价、会员到期或券模板修改都不会重写历史。

如果库存不足或锁券失败，订单、券和库存一起回滚。重复提交相同订单号返回同一订单，不重复预占。

## 测试证据

RED 阶段有 6 个缺少快照/服务的编译错误。实现后计价与真实数据库订单共 3 个测试通过，覆盖金额溢出、最低 0 元、会员后用券和幂等预占。
