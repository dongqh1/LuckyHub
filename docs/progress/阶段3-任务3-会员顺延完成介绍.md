# 阶段 3 · 任务 3：会员顺延完成介绍

## 完成内容

实现月卡、季卡、年卡产品，用户会员权益查询，以及基于业务号的幂等购买。会员变化锁定用户行，保存不可变发放历史；折扣率、每日抽奖加成和积分倍率作为当前权益快照保存。

## 举例

用户的年卡还有 30 天到期，现在又购买 365 天年卡。系统不是从今天重新算 365 天，而是从原到期日继续增加 365 天，所以原剩余 30 天不会丢失。

如果客户端因网络超时把 `BUY-YEAR-001` 重发 10 次，只有一条发放记录，会员只延长一次。换产品或用户复用该业务号会返回幂等冲突。

## 测试证据

RED 阶段有 6 个缺少服务/DTO 的编译错误。实现后 3 个服务与并发测试通过；另修复了 Java 纳秒与 MySQL 毫秒精度差异，保证首次和重试响应时间完全一致。
