# 阶段 3 · 任务 1：商业交易数据库完成介绍

## 完成内容

新增三次只追加迁移：V11 优惠券、V12 会员、V13 现金订单与模拟支付。共建立 8 张表、9 项权限，并为状态、金额、有效期和业务编号设置 CHECK 或唯一约束。V1-V10 未修改。

## 举例

一张“满 100 元减 20 元”的券由 `coupon_template` 保存规则；发给用户后由 `user_coupon` 保存独立券号和状态。用户购买年卡时，`membership_grant_record` 保存不可变发放历史。购买商品时，`mall_order` 保存原价、会员优惠、券优惠和应付金额四段快照，`payment_order` 使用独立支付号防止重复回调。

即使应用代码出错，数据库仍会拒绝负金额、非法状态、结束时间早于开始时间以及重复业务号。

## 测试证据

测试先得到 3 个失败和 1 个缺类错误；实现 V11-V13 与领域枚举后，4 个契约测试全部通过，Flyway 从版本 10 连续迁移到版本 13。
