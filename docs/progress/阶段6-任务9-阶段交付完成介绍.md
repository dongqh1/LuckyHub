## 新电脑和空数据库的具体例子

假设小李拿到一台新电脑，没有旧的 LuckyHub 数据。他先启动 MySQL 和 Redis，复制 `.env.example` 为 `.env` 并配置本地值，再提供测试用的 32 字节地址密钥与回调 secret。运行正式空库脚本后，一个随机 schema 会经历 `V1 -> ... -> V17`，得到 48 张业务表，然后自动撤权并删除。

接着小李运行 package 并启动 `target/luckyhub-0.0.1-SNAPSHOT.jar`。浏览器访问 `http://localhost:<端口>/v3/api-docs`，能看到地址、`POST /api/benefits/{id}/claim`、用户发货单与 tracking、签名 callback、管理员发货操作和模拟物流事件。这样可以确定“空库可迁移、JAR 可运行、接口可发现”三件事都成立，而不是依赖开发者旧电脑里的残留状态。
