# 阶段 3 · 任务 2：优惠券资产完成介绍

## 完成内容

实现优惠券模板、幂等发券、本人券查询，以及 `AVAILABLE -> LOCKED -> USED`、取消释放和到期状态机。发券时锁定模板行控制每人上限；锁券使用条件 SQL，两个订单不能同时占用同一张券。

## 举例

用户得到一张“满 100 元减 20 元”券。订单 A 以 120 元折后金额锁券成功，订单 B 同时锁同一券会返回状态冲突。A 取消时券回到 AVAILABLE；若 A 支付成功则变为 USED，之后不能释放或再次使用。

指定商品券会校验商品 ID；不允许叠加会员的券在用户已使用会员折扣时会被拒绝。优惠最多抵到 0 元，不产生负应付金额。

## 测试证据

RED 阶段因缺少服务和 DTO 得到 6 个编译错误。实现后 3 个服务/并发测试通过，包括两个订单并发抢一张券只有一个成功。
